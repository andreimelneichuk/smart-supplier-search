# 🥫 B2B Food Supplier Intelligence & Procurement Copilot

Интеллектуальный сервис для поиска, гео-ранжирования, многофакторного сравнения и принятия решений при закупках продуктов питания и ингредиентов.

Разработано в рамках тестового задания на позицию **AI Generalist / AI Automation Specialist**.

---

## 🚀 Ключевые возможности

1. **Каскадный гибридный поиск (Hybrid Search & Reranking)**:
   * **NLP / Морфология**: глубокая лемматизация через `pymorphy3` с анализом предлогов и синтаксических ролей («мясо курицы» vs «приправа для курицы»).
   * **Multi-field BM25**: канонический BM25 с отдельными весами для названия компании, специализации, категории, описания и LLM-ключевых слов.
   * **Cross-Encoder Transformer**: локальный трансформер `BAAI/bge-reranker-v2-m3-int8` через ONNX Runtime — мгновенное локальное переранжирование кандидатов без затрат на API.
   * **LLM Reranker (Groq / Qwen 3.8)**: точечная оценка релевантности сложных B2B-запросов.

2. **Гео-ранжирование и логистический скоринг**:
   * Определение города из свободного текста запроса («сыр моцарелла Казань»).
   * База 1100+ городов РФ (`city.csv`) + геокодер OpenStreetMap Nominatim с кэшированием.
   * Экспоненциальное затухание оценки по удаленности (`exp(-dist / 400 км)`) с интеграцией в общий скор.

3. **🤖 AI-Ассистент по закупкам (Procurement Decision Copilot)**:
   * **Умный сбор в Сравнение (AI-Selection)**: по одной кнопке *«Отобрать подходящих в Сравнение (через AI)»* LLM сканирует поисковую выдачу, отсекает ложные омонимы (например, котлеты с сыром при поиске сыра) и отбирает 2–4 целевых производителя прямо на вкладку сравнения.
   * **Принятие решений**: на экране сравнения LLM детально сопоставляет выбранных кандидатов, анализирует логистические плечи, профиль производства и риски.
   * **План Б**: определяет, в каких сценариях переключаться на резервного поставщика.
   * **Outreach-генератор**: автоматически генерирует вежливый персонализированный скрипт первого контакта для WhatsApp / Telegram / Email с подстановкой всех параметров сделки.

4. **📦 Глубокий B2B-Паспорт товара и компании (On-Demand AI Audit)**:
   * **Решение проблемы неполноты баз**: вместо попыток медленно выкачивать весь терабайтный интернет-каталог поставщиков под угрозой блокировок, система использует **JIT (Just-In-Time) On-Demand экстракцию**.
   * **Модальное окно `@st.dialog`**: по клику на *«🔍 B2B-Паспорт»* LLM в реальном времени анализирует полный текст карточки и формирует структурированное B2B-досье с кэшированием в SQLite:
     * **Коммерческие условия**: минимальный заказ (MOQ), кванты отгрузки, тара/фасовка, условия оплаты (предоплата/отсрочка, НДС).
     * **Качество и комплаенс**: ГОСТ / ТУ, ХАССП (HACCP), декларация ЕАС, ФГИС «Меркурий», «Честный Знак».
     * **Логистика**: температурный режим (рефрижератор / заморозка / сухой склад), география и варианты доставки (самовывоз, паллеты, ТК по РФ).
     * **Экспертиза байера**: автоматический аудит с выявлением **Green Flags** (плюсы), **Red Flags** (скрытые риски) и **3 конкретных вопросов** менеджеру для первого созвона.
   * **100% полнота данных**: вкладка с полным не обрезанным исходным текстом карточки компании и структурированными товарными признаками (сорта, фасовка, применение в HoReCa).

5. **Встроенная Multi-Tenant Mini-CRM для закупщиков**:
   * **Мульти-организационность**: изоляция данных разных компаний (например, «Додо Франчайзинг», «ВкусВилл», «HoReCa Рестораны»). Каждая компания видит только свои статусы и заметки.
   * **Атрибуция авторов**: фиксация имени и роли байера, изменившего статус или оставившего комментарий.
   * **Хронологический таймлайн (Audit Log)**: полная история взаимодействия с поставщиком по компании с датами, авторами и деталями созвонов/переписки.
   * **Статусы переговоров**: цветовые индикаторы (*«Не связывались»*, *«Отправлен запрос КП»*, *«Ждем прайс»*, *«Договорились»*, *«Отказ»*).
   * **Фильтр пайплайна**: чекбокс *«Только в работе у нашей организации»* для моментального вывода воронки закупки.
   * **Управление прямо из карточки**: редактирование статуса и добавление заметок доступно как в общей выдаче, так и прямо внутри модального B2B-паспорта.

6. **Метрики качества поиска**:
   * Скрипт `parser/eval_search.py` с автоматическим расчетом метрик **P@10** и **nDCG@10** на размеченном золотом датасете `parser/eval_labels.json`.

## 🛠️ Стек технологий

* **Frontend / UI**: [Streamlit](https://streamlit.io/)
* **База данных**: SQLite (2500+ производителей продуктов питания, кэш геокоординат, CRM-заметки, B2B-параметры)
* **NLP & IR**: `pymorphy3`, кастомный multi-field `BM25Index`
* **ML / Neural Search**: FastEmbed, ONNX Runtime (`BAAI/bge-reranker-v2-m3-int8`)
* **LLM**: Groq API / Qwen 3.8 / OpenAI API
* **Парсинг & Live Scraper**: BeautifulSoup4, Requests, Circuit Breaker от блокировок

## 📦 Быстрый старт

### 1. Клонирование и настройка окружения

```bash
git clone https://github.com/andreimelneichuk/smart-supplier-search.git
cd smart-supplier-search

python -m venv .venv
source .venv/bin/activate  # на Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Настройка переменных окружения

Скопируйте шаблон `.env.example` в `.env`:
```bash
cp .env.example .env
```
Укажите ваш API-ключ в файле `.env` (по умолчанию настроен Groq с моделью `qwen/qwen3.8-27b`).

### 3. Запуск сервиса

```bash
streamlit run parser/app.py
```
Приложение откроется в браузере по адресу `http://localhost:8501`.

## 📊 Структура проекта

```text
├── parser/
│   ├── app.py                 # Основной веб-интерфейс (Streamlit)
│   ├── advisor.py             # AI-ассистент закупщика и B2B-обогащение (Groq)
│   ├── db.py                  # Работа с SQLite (поставщики, заметки CRM, B2B-поля)
│   ├── ranking.py             # Формула многофакторного скоринга

│   ├── geo.py                 # Офлайн-база городов РФ и расчет расстояний
│   ├── live.py                # Live-добор поставщиков и контактов на лету

│   ├── eval_labels.json       # Датасет для валидации поиска

├── requirements.txt           # Зависимости Python
├── .env.example               # Пример конфигурации API
└── README.md                  # Документация проекта
```
